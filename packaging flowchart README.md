# Compact Solar-Powered Agarbatti Drying & Packaging System

## 1. System Flow

### 1.1 Drying → Packaging Pipeline

```
Dried Agarbatti
      ↓
    Tilted
      ↓
 IR Sensor (counts sticks)
      ↓
 Required Quantity Reached?
      ↓
 Automatic Stopper / Bundling
      ↓
 Craft Paper Wrapping
      ↓
 Finished, Packed Agarbatti
```

### 1.2 Power Flow

```
Solar Panel
      ↓
Charge Controller
      ↓
    Battery
    ├── Drying subsystem
    └── Packaging subsystem
```

---
## 1.3 Battery information
*Charging time*
The 500W panel gives ~350-400 W in real sunlight.

From 50% to full (900 Wh): ~2.5 hrs

From empty to full (1800 Wh): ~5 hrs of good sun. 

The 40A controller can handle the panel current (~36A).
